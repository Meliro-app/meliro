# Meliro

*Anciennement Merge.*

Réviser ses cours avec une IA qui tourne sur ton Mac : fiches, flashcards et cartes mentales écrites à partir de tes cours (PDF, Word, PowerPoint), chaque point renvoyant à sa page du cours. Gratuit, sans abonnement. Tes cours ne quittent jamais ton Mac.

**Télécharger :** https://github.com/Meliro-app/meliro/releases/latest

**Pour qui :** un Mac avec puce Apple (M1 ou plus récent), 8 Go de mémoire, macOS 26 ou plus récent pour l'IA, et environ 31 Go libres pour l'installer (14,3 Go gardés ensuite). Pas encore sur PC ni sur téléphone. Les QCM, les exercices et le planning arrivent plus tard.

L'IA (Gemma 4, licence Apache 2.0) est hébergée sur https://huggingface.co/Meliro-app/meliro-ia et s'installe depuis l'app.
